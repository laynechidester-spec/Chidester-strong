# Chidester Strong

Mobile-friendly family training prototype.

## Features
Two athlete profiles, four workout focuses, gym/hotel/home modifications, workout checklists, weights, notes, feedback, training history, goals, and JSON backup.

## Deployment
GitHub repository Settings → Pages → Deploy from a branch → main → / (root). After deployment, open https://laynechidester-spec.github.io/Chidester-strong/

## Important limitations
No login, cloud sync, Apple Health, Oura integration, or medically personalized exercise programming. Data stays in browser local storage on each device. Export backups regularly. Do not enter private health details into a public GitHub repository.
